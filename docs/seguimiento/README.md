# Seguimiento de avance

Un archivo por módulo, para saber qué está hecho sin depender de `gh` ni de los PR de GitHub.

**Estados:** ✅ en `main` · 🔨 en curso o en PR abierto · ⏳ pendiente.

**Reglas**
- Solo el dueño del módulo edita su archivo, así no hay conflictos entre integrantes.
- Se actualiza en el último commit de cada PR; llega a `main` junto con el trabajo.
- El número de PR se escribe con `#`. Si el PR aún no existe, se deja vacío y se completa en el PR siguiente.
- Para ver el panorama completo basta leer los archivos de esta carpeta y la tabla de estado del `AGENTS.md`.
